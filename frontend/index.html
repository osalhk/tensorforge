How it works

Each ticket gets a primary category (11 types), an optional secondary category, an urgent flag and the team it is routed to. The model only reads the channel, subject and text. Tickets with confidence below 0.5 are flagged for human review. All predictions come from the same authenticated API the judges use (/predict, /predict/batch, /batch/jobs).
